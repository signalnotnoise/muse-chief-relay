## Five gaps

1. **Composer selection is not a wire stamp.** `chatFrame(text)` sends exactly `{v:1,type:"chat",text}`; the caller supplies only trimmed text. Room is supplied at join, not in each chat. `openWorkspaceKey` only filters the transcript, and folder keys are normalized goal text rather than verified registry keys. Sources: [relayProtocol.js 37–56](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/src/relayProtocol.js#L37-L56), [useChat.js 254–265](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/src/useChat.js#L254-L265), [App.vue 84–98](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/src/App.vue#L84-L98), [workspaceFolder.js 45–79](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/src/workspaceFolder.js#L45-L79).

2. **The transcript loses the accepted UUID and routing context.** `appendChat` retains nick/text; `appendRow` replaces identity with `++rowSeq` and uses local display time. Received `id`, `room`, `ts`, workspace and parent metadata do not survive. Replay takes the same path. These row IDs cannot be reply-parent UUIDs. Source: [useChat.js 234–301](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/src/useChat.js#L234-L301).

3. **C# normalization preserves extras; `MirrorPayload.Build` drops them.** Normalization adds missing `cmd`/`channel` aliases without projecting other fields away. Chat dispatch supplies the object and configured channel fallback. Build then hashes `channel ?? room ?? fallback`, lowercases the UUID, trims nick, normalizes timestamp, forces `threadKey:"room"`, and emits only `id/workspaceKey/sender/text/ts/threadKey`. Explicit workspace, parent, routing version and provenance disappear. The interface has no separate relay-authority/canonical-room context; this is an unestablished interface guarantee, not a server-security finding. Sources: [Frames.cs 53–103](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/src/ChatBridge/Frames.cs#L53-L103), [HackChatBridge.cs 580–614](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/src/ChatBridge/HackChatBridge.cs#L580-L614), [HivemindMirror.cs 69–112](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/src/ChatBridge/HivemindMirror.cs#L69-L112).

4. **JS is a second metadata-loss boundary.** `planRoomMirror` can accept an explicit key, but constructs only workspace `{key,createdTs}` and message `{workspaceKey,threadKey,sender,text,ts}`, plus a separate document ID. Route metadata is omitted. Adding fields directly to the message would currently fail the schema's unknown-field check. Sources: [hivemind.js 60–72](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/hivemind.js#L60-L72), [102–108](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/hivemind.js#L102-L108), [365–424](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/hivemind.js#L365-L424).

5. **Spill/helper shape lacks routing stages and verified completion.** Memory and overflow spill carry `built.Json` unchanged. Spill reading checks only that a line is a JSON object; that string goes to helper stdin. The loop advances spill after an attempt even when processing fails. JS parses one object, queues `{plan,resolve}`, retries in memory, then discards the returned result at its process entry point. No pending-resolution/ready-write distinction exists. Current client exports also contain no workspace/message/routing-issues reader. These are later handoff constraints, not authority to begin durable-envelope implementation before Gate 0. Sources: [HivemindMirror.cs 232–348](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/src/ChatBridge/HivemindMirror.cs#L232-L348), [486–543](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/src/ChatBridge/HivemindMirror.cs#L486-L543), [messageMirror.js 127–203](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/messageMirror.js#L127-L203), [hivemindClient.js 372–383](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/web/muse/hivemindClient.js#L372-L383).

- **Required reply:** UUID B references `parentMessageId:A`; omit workspace for inheritance. Never substitute the web row counter. A known explicit beta/alpha-parent mismatch must block in the composer and reject if bypassed.

The hash is the existing [SHA-256(`abc`) fixture](https://github.com/signalnotnoise/muse-chief-relay/blob/93dc614bcedbe05ae22d56914a413e113bdf0324/tests/Chief.Bridge.Tests/HivemindMirrorTests.cs#L9-L18); parent/version/provenance are absent.
- **Required authority cases:** invalid/missing accepted UUID, absent trusted room context, conflicting room aliases and client-supplied provenance must not silently establish a valid route. Document the adapter's trusted context and derive the contract proof there.
