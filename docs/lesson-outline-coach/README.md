# Lesson outline coach

A teacher drops a lesson outline. The agent runs the SME-gate checklist, writes a critique as a hive-mind note, and appends a room-board task.

This is the first teaching-kit card. Alex made the classroom / lesson-coach kit build priority #1 (`knowledge/classroom-kit-priority.md`). Medical stays parked. 3D asset-QA stays a promo angle.

| Piece | Where |
|---|---|
| Checklist the agent runs | [sme-gate-checklist.md](sme-gate-checklist.md) |
| Critique note the agent files | [critique-note.md](critique-note.md) |
| Playbook (when to run, trust, board update) | [../../agents/lesson-outline-coach.md](../../agents/lesson-outline-coach.md) |
| Shape, indexed in the hive mind | `knowledge/lesson-outline-critique-shape.md` |

The checklist is judgment. There is no validator command and no score. Marks are `met`, `partial`, and `missing`. The verdict is `ready`, `revise`, or `blocked`.

The room board cannot store in-progress or subtasks. Task 2 stays `claimed` until the room appends a later line with the same id and state `done`. How to append that line, and how to append a task for one outline, is the playbook.
